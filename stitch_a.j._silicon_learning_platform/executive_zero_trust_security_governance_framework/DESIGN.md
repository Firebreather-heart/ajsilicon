## Brand & Style

The design system establishes an atmosphere of uncompromising institutional authority, cryptographically verified integrity, and executive rigor. Created for senior audit directors, CISO-track candidates, and risk advisory boards, the interface evokes the gravitas of elite certification bodies alongside the real-time operational posture of mission-critical defense operations centers.

The aesthetic fuses **Corporate High-Precision Modernism** with **Zero-Trust Telemetry Styling**:
- **Dual-Zone Layout Architecture:** Operates with high-density Midnight Navy command structures (sidebars, live telemetry headers, audit trail panels) framing sterile, hyper-legible Crisp Slate exam and dossier workspaces.
- **Institutional Weight:** Information density is intentional, structured, and audit-ready. UI elements prioritize clear categorical hierarchies, cryptographic proofs of integrity, and defensive resilience over decorative ornamentation.
- **Defensive Restraint:** Interfaces avoid frivolous transitions or whimsical metaphors. Statuses are definitive, immutable, and strictly verified through calibrated emerald indicators, amber regulatory cautions, and electric technical cyan telemetry nodes.

## Colors

The system uses a calculated chromatic model designed for extended, fatigue-free analytical review during intensive simulation testing, audit reporting, and telemetry scrutiny.

### Primary & Core Tones
- **Primary Navy (`#0A192F`):** Deep institutional anchor applied across global navigation, control command bars, active table headers, and primary administrative CTAs.
- **Deep Midnight Base (`#060D17`):** The structural bedrock for terminal surfaces, sidebar backgrounds, command consoles, and biometric authorization zones.
- **Crisp Canvas Surface (`#F8FAFC` & `#FFFFFF`):** High-clarity white surfaces dedicated to exam simulation cards, formal compliance questionnaires, and audit documentation viewports.

### Specialized Accent Roles
- **Verification Emerald (`#10B981` / `#059669`):** Reserved exclusively for verified compliance passing, signed public key certificates, active DRM streams, hardware 2FA confirmation, and zero-error test results.
- **Pedigree Amber (`#F59E0B` / `#D97706`):** Honors accreditation milestones, high-stakes warnings, credential expirations, and regulatory audit review requirements.
- **Cryptographic Cyan (`#0EA5E9`):** Dedicated to technical runtime elements: SHA-256 integrity hashes, candidate IP tracking strings, active packet telemetry, and proctored examination countdown timers.

### Border & Hairline Framework
- Light surface hairlines rely strictly on `#E2E8F0`.
- Dark console hairlines leverage `#1E293B`, producing crisp 1px structural separations without visual weight.

## Typography

The typographic pairing contrasts institutional governance authority against rigorous mathematical precision.

- **Plus Jakarta Sans (Headlines, Body, Categorical Navigation):** Selected for its geometric discipline, clear vertical stems, and commanding executive posture. Maintains pristine readability across dense examination cases, situational question stems, and statutory clauses.
- **JetBrains Mono (Technical Displays, Telemetry, Hashes, Currency Feeds):** Formally applied to non-prose elements including candidate session tokens, Paystack/Flutterwave transaction references, DRM lock state vectors, SHA-256 ledger signatures, and proctor time clocks. 

### Typographic Governance Rules
- All numeric displays across tables, timers, scores, and monetary settlements must use tabular lining figures (`font-variant-numeric: tabular-nums`) to ensure vertical column alignment across dense auditing spreadsheets.
- Monospace strings exceeding 24 characters must retain truncation with copyable tooltips, formatted in lowercase with uppercase cryptographic prefixes (`SHA256:`, `TX_ID:`).

## Layout & Spacing

The layout is built upon an uncompromising 12-column grid optimized for split-screen auditing workflows:
- **Desktop (>=1280px):** 12 columns, 24px gutters, fixed-width high-density navigation sidebar (260px) alongside an adaptive operational core (min 960px). Telemetry side-drawers occupy a fixed 380px panel when engaged.
- **Tablet (768px - 1279px):** 8 columns, 20px gutters, collapsible command rail with full-width reading docks.
- **Mobile (<768px):** 4 columns, 16px gutters, 16px margins, sticky bottom confirmation and proctoring HUD bars.

### Spacing Philosophy
Compact vertical cadence (`space-sm` and `space-md`) dominates operational control clusters to prevent informational fragmentation. High-stakes question cards introduce generous padding (`space-xl`) to promote focused cognitive engagement free from incidental visual friction.

## Elevation & Depth

Visual hierarchy is maintained through **Low-Contrast Outlines** and **Precision Tonal Layering** rather than exaggerated optical drops. Depth conveys active execution states and physical access layers:

- **Level 0 (Base Substrates):** Solid `#060D17` (command environments) or `#F8FAFC` (dossier workspaces).
- **Level 1 (Card & Content Blocks):** Pure `#FFFFFF` surfaces bounded by 1px `#E2E8F0` hairline borders. No ambient blur; structure is defined by exact edge borders.
- **Level 2 (Active Examination / Proctored Panels):** Elevated via a calibrated ambient shadow: `0 4px 16px -2px rgba(10, 25, 47, 0.06), 0 0 0 1px #E2E8F0`.
- **Level 3 (Diagnostic Drawers & Telemetry Modals):** Grounded by a deep executive shadow: `0 12px 32px -4px rgba(6, 13, 23, 0.28), 0 0 0 1px #1E293B`.
- **Secure Watermark Substrates:** Document viewports incorporate repeated, semi-transparent background vector micro-watermarks (`rgba(10, 25, 47, 0.03)`) displaying timestamped candidate IDs and proctor tracking nodes.

## Shapes

The design system enforces a disciplined geometric profile using **Soft (Level 1)** corner architecture:
- Micro elements (status pills, telemetry chips, cryptographic tags) employ exact `4px` (`0.25rem`) corner radiuses to convey technical rigidity.
- Standard modules (exam question containers, audit reconciliation panels, terminal windows) implement an 8px (`rounded-lg`) border radius.
- Interactive controls reject circular or pill silhouettes; all actions adhere to structured orthogonal boundaries that preserve institutional discipline.

## Components

### Buttons & Operational Triggers
- **Primary Institutional CTA:** Solid Deep Navy (`#0A192F`) fill, crisp white typography (`Plus Jakarta Sans`, 600 weight), 8px border radius, 40px default height. Hover states transition cleanly to `#1E293B` with no dimensional elevation shifts.
- **Audit Action CTAs (Verified Sign-Off):** Precision Emerald (`#10B981`) fill, `#060D17` dark-slate text, accented with an inline lock icon.
- **Secondary Outlined Actions:** `#FFFFFF` background, 1px `#E2E8F0` border, `#0A192F` typography, shifting to `#F8FAFC` on focus/hover.

### Status Indicators & Badges
- **DRM Active & Telemetry Locks:** JetBrains Mono 11px uppercase labels, framed by 1px borders. Active state: `#10B981` text over `rgba(16, 185, 129, 0.08)` background with a pulsing 6px indicator beacon.
- **Prestige / Advisory Badges:** Commemorative and accreditation recognitions (e.g., ISACA Lagos 30th Anniversary leadership distinctions) utilize a dual-tone border: `#F59E0B` border, dark navy core `#0A192F`, and gold typography.

### Input Fields & Exam Multiple-Choice Modules
- **Question Options:** Full-width selectable cards. Inactive state: 1px `#E2E8F0` border, `#FFFFFF` background. Selected state: 2px `#0A192F` structural stroke, inset `rgba(10, 25, 47, 0.02)` fill, bold indicator label.
- **Text & Hash Entry:** High-contrast white inputs with 1px `#CBD5E1` borders, transitioning to `#0EA5E9` (Cyan) focused outline with zero offset.

### Paystack / Flutterwave Reconciliation Tables
- Tabular data grids built with fixed 44px rows, alternating subtle zebra stripes (`#FFFFFF` to `#F8FAFC`), 1px `#E2E8F0` horizontal borders, and zero vertical borders.
- Transaction references, customer IDs, and settlement hashes are anchored in `JetBrains Mono` at 12px with explicit right-aligned numerical amounts.

### Document Viewer Frame
- Surrounded by an institutional header bar containing live DRM heartbeat indicators, encrypted session hash displays, and automated candidate IP binding tags.
- Canvas implements an unobtrusive diagonal dynamic security watermark displaying: `CONFIDENTIAL - PROCTORED SESSION - [CANDIDATE_ID] - [TIMESTAMP]`.
