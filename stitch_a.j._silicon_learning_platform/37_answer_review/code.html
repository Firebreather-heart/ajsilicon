Question Scenario

During an IT audit of a commercial banking institution, an IS auditor identifies that database administrators (DBAs) possess full administrative privileges enabling direct table schema changes, automated script executions, and direct update privileges over production financial ledgers without separate developer staging. Which of the following recommendations represents the MOST effective compensating control to mitigate the risk of unauthorized data alterations?

Answer Evaluation
A
Requiring quarterly supervisor sign-offs on database account active listings.
B
Implementing continuous automated alerting to the IT security manager whenever standard database maintenance windows are scheduled. cancel Your answer (Incorrect)
C
Enabling immutable database transaction logging shipped offsite to write-once media with independent daily reconciliation against financial journals. check_circle Correct answer
D
Enforcing annual non-disclosure and conflict of interest agreements across all privileged administrative staff.
menu_book Explanation & ISACA Standards Alignment

Core Principle: In circumstances where strict segregation of duties (SoD) cannot be enforced—such as small DBA departments having broad access across database production engines—independent, tamper-evident audit logging combined with daily third-party reconciliation serves as the primary compensating detective control.

Why Option C is correct: Sending database modification logs to immutable or offsite storage ensures that even a superuser or DBA cannot delete evidence of illicit manipulation. Independent financial reconciliation verifies ledger integrity against external sources, discovering discrepancies rapidly.

Why Option B is incorrect: While automated schedule notifications provide administrative visibility, they fail to record or detect the actual granular SQL transactions executed during or outside scheduled maintenance intervals.

Reference: CISA Review Manual (CRM 27th Edition), Section 2.3.2: Compensating Controls & Privileged Access Architecture ISACA Task Statement: T2.4 (Evaluate IT Organization & Personnel Controls)
